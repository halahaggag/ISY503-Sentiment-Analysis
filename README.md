# ISY503-Sentiment-Analysis
# ISY503 Amazon Review Sentiment Analysis

# Project overview

This project was developed for ISY503 Intelligent Systems Assessment 3.

The project trains a neural network to classify Amazon product reviews as either:

- Positive
- Negative

The final system will include a simple user interface where a user can enter a product review and receive a sentiment prediction.

# Project objectives

- Load labelled Amazon product reviews
- Clean and preprocess review text
- Encode and pad text sequences
- Split data into training, validation and test sets
- Train and evaluate a neural network
- Build a simple sentiment prediction interface
- Examine ethical considerations associated with sentiment analysis
